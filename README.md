# Ranking TESS Planet Candidates by Host-Star Geochemistry

Work in progress 

## Goal 
Join NASA's TESS Object of Interest catalog to the Hypatia Catalog of stellar abundances, and rank unconfirmed planet candidates by weather their host starts have the chemistry to build a geologically active, biologically viable rocky planet.
